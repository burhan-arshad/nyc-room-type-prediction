    How it works

    1. Your listingTen values are checked in the browser, then sent with the Fetch API.
    2. FastAPI + PandasThe server validates the input and arranges it into a one-row table.
    3. Scikit-learn pipelineA model loaded with Joblib returns the room type and a probability for every class.
    4. Your resultThe response is validated and drawn as animated bars.

    Built with HTML, CSS and Vanilla JavaScript, FastAPI, Pandas, Scikit-learn and Joblib.
