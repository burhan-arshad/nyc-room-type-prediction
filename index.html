    Methodology

    One request, six stages. Each hand-off below is something this project actually does.

    1. Listing featuresTen values typed into the form.
    2. Frontend validationRanges and types checked before anything is sent.
    3. FastAPIReceives JSON at /predict and validates it again.
    4. Scikit-learn pipelinePreprocessing and classifier produce class probabilities.
    5. Prediction responsePredicted class, class names, probabilities.
    6. Results visualizationResponse is validated, then drawn as bars.
    HTML, CSS, Vanilla JavaScript
    The whole interface in three files, with no framework or build step.
    Fetch API
    Checks the API at / for the status light and posts listings to /predict.
    FastAPI
    Serves the endpoints and enforces the input schema.
    Pandas
    Arranges each request into a one-row DataFrame with the model's columns.
    Scikit-learn
    The trained pipeline that classifies the listing and estimates class probabilities.
    Joblib
    Loads the serialized pipeline when the server starts.
